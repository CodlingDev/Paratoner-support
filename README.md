# Paratoner 지원

Paratoner는 Apple Silicon Mac에서 USB-C 단자와 연결된 외장 화면 및 오디오 상태를 확인하는 메뉴 막대 앱입니다. macOS 14 이상이 필요합니다.

메뉴 막대의 번개 아이콘을 누르고, Mac 그림에서 단자를 선택하세요. 연결된 장치와 사용 가능한 제어 항목이 나타납니다.

문제를 제보할 때는 Mac 모델, macOS 버전, 연결 장치 모델과 문제를 재현하는 순서를 알려주세요. 공개 이슈에 일련번호나 개인정보를 올리지 마세요.
